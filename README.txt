念日 · 隐私与支持网站

此仓库仅包含念日的公开隐私政策、帮助文档及网页源文件，不包含原生应用源码或用户日期数据。

发布者：何年金
支持邮箱：nj.he@foxmail.com
网站：https://h-koala.github.io/nianri-docs/
隐私政策：https://h-koala.github.io/nianri-docs/privacy/
帮助支持：https://h-koala.github.io/nianri-docs/support/

语言
简体中文：/privacy/、/support/
繁體中文：/zh-Hant/privacy/、/zh-Hant/support/
English：/en/privacy/、/en/support/

维护
1. 在 content/policy.json 更新三语言政策与常见问题。
2. 在 site-config.json 更新发布者、联系邮箱、更新日期及网站地址。
3. 运行 python tools/build.py 生成 docs 内的静态页面。
4. 提交并推送 main。GitHub Pages 从 main 分支的 /docs 目录发布。
5. 检查所有语言、移动端和公开网址，确保 App 内说明与网站一致。

网页不依赖外部字体、广告、分析服务或第三方前端库。基础导航、隐私正文和FAQ在关闭JavaScript时仍可使用。
少量JavaScript只处理目录高亮、语言菜单关闭及用户点击复制邮箱；不写入Cookie或本地存储。
GitHub Pages 会按自身政策记录网站访问数据，包括用于安全目的的IP地址；政策已单独说明。
联系邮件由用户主动发送到上述邮箱，不在网站内收集或提交表单。

隐私文案应随真实产品行为更新；不要在实际加入数据采集、云同步或其他服务后继续使用过期声明。
