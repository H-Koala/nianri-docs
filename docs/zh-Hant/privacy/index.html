隱私政策

本政策由 何年金 發布，說明念日應用程式及本支援網站如何處理資訊。如有隱私問題，請聯絡 nj.he@foxmail.com。

你的日期留在裝置上。 了解資訊如何被處理，隨時作出自己的選擇。

01

本機記錄與無需註冊

念日無需建立應用程式帳號，不接入廣告或行為分析服務。你輸入的日期、標題、備註、分類及提醒設定在裝置上處理，不上傳至開發者伺服器。應用程式不會要求你提供電子郵件地址來使用日期記錄功能。

02

通知權限與鎖定畫面

提醒透過 iOS 本機通知安排，需由你允許通知。標題及提醒內容可能顯示在鎖定畫面或通知中心；你可在系統設定中調整預覽方式、聲音或關閉通知。關閉權限不影響查看本機記錄。

已排程的提醒可由系統在應用程式關閉時傳送。背景補排由 iOS 決定，容量和系統設定會影響提醒；念日不承諾永久無需開啟應用程式或每則提醒一定顯示。

03

本機資料庫與備份

記錄使用裝置內的 資料庫儲存，念日不提供應用程式層面的自動雲端同步。依照你的裝置設定，系統備份可能包含應用程式資料。

你可主動將 JSON 備份匯出至「檔案」、iCloud Drive 或其他自選位置。匯出檔案未加密，可能含姓名、日期和備註，請自行選擇可信的儲存位置與分享對象。所選儲存服務依其自身規則處理檔案。

04

小工具與便捷輸入（自 V0.4 起）

App 在本機與小工具擴充功能共享必要的日期快照，包括日期規則、標題與語言，不包含備註或購買資訊，不上傳至開發者伺服器。標題可能出現在主畫面或鎖定畫面；可在念日的小工具設定中關閉標題顯示。iOS 控制已顯示內容的更新時機。

便捷輸入讀取你主動選取的 CSV/TSV 檔案或貼上的表格，在本機預覽與檢查，確認後僅新增勾選的有效日期，不覆蓋原資料。JSON 備份匯入則會在確認後取代資料庫。檔案提供者可能依自身規則從雲端下載你選擇的檔案。

05

Apple 購買與權益

Pro 購買由 Apple 的 App Store 與 StoreKit 處理。應用程式讀取及驗證 Apple 提供的交易與權益狀態，以開啟購買的功能；開發者不會收到你的付款卡資訊。

回復購買使用你的 Apple 購買記錄，可能需要由 Apple 驗證帳號。JSON 備份不包含或轉移 Pro 權益。Apple 對購買記錄的保留與處理適用其服務條款與隱私規則。

06

手動加入系統行事曆

你選擇「加入系統行事曆」時，念日將該次日期的標題、備註和日期交給 Apple 的系統編輯器，由你確認是否儲存及儲存至哪個行事曆。應用程式不要求完整行事曆讀取權限，也不持續讀取你的行事曆。

此操作只新增一次事件，不提供雙向同步。之後在念日修改或刪除記錄，不會同步修改或刪除已儲存的系統行事曆事件；再次新增可能產生重複。行事曆服務的同步與儲存取決於你選擇的行事曆及系統設定。

07

保留、匯出與刪除

本機記錄保留至你在應用程式中刪除、以備份取代，或系統移除相關應用程式資料。你可在設定中匯出備份並逐項刪除日期。匯入前會要求確認取代目前資料，請先儲存需要保留的備份。

刪除應用程式可能移除本機記錄；保留資料的卸載等系統操作與刪除應用程式不同。你自行儲存的匯出檔案、裝置備份和系統行事曆事件需在對應位置單獨管理。由於開發者沒有你的本機日期副本，無法遠端回復或刪除它們。

08

自願傳送的支援郵件

如你聯絡 nj.he@foxmail.com，何年金 將收到你的電子郵件地址，以及你主動提供的內容或附件，用於回覆、排查問題和跟進請求。郵件會透過電子郵件服務商傳輸及儲存。

請只提供解決問題所需的資訊，不要傳送 Apple 帳號密碼、付款卡資料或未遮蓋的完整日期備份。支援記錄僅在解決問題、必要跟進或依法需要的期間保留；不再需要時刪除或移除可識別身分的資訊。你可透過同一信箱申請刪除支援郵件，依法需要保留的部分除外。

09

本網站與 GitHub Pages

本網站使用 GitHub Pages 託管，不加入廣告或行為分析指令碼。GitHub 會為安全目的記錄並儲存訪客 IP 位址，無論訪客是否登入 GitHub。

此網站存取記錄不同於念日裝置內的日期資料。GitHub 對網站託管資料的處理、儲存與相關權利說明見頁尾的 GitHub 隱私聲明；請勿將敏感個人資料提交至公開的 GitHub 頁面。

10

政策更新與聯絡

應用程式或網站的資訊處理方式改變時，本政策會更新，並標明更新日期。政策內容應以你正在使用的版本及實際處理方式為準。
