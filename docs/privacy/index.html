隐私政策

本政策由 何年金 发布，说明念日应用及本支持网站如何处理信息。如有隐私问题，请联系 nj.he@foxmail.com。

你的日期留在设备上。 了解信息如何被处理，随时作出自己的选择。

01

本地记录与无需注册

念日无需创建应用账号，不接入广告或行为分析服务。你输入的日期、标题、备注、分类及提醒设置在设备上处理，不上传至开发者服务器。应用不会要求你提供邮箱来使用日期记录功能。

02

通知权限与锁定屏幕

提醒通过 iOS 本地通知安排，需由你允许通知。标题及提醒内容可能显示在锁定屏幕或通知中心；你可在系统设置中调整预览方式、声音或关闭通知。关闭权限不影响查看本地记录。

已经排程的提醒可由系统在应用关闭时发送。后台补排由 iOS 决定，容量和系统设置会影响提醒；念日不承诺永久无需打开应用或每条提醒一定展示。

03

本地数据库与备份

记录保存在设备内的应用空间，念日不提供应用层面的自动云同步。根据你的设备设置，系统备份可能包含应用数据。

你可主动将 JSON 备份导出至“文件”、iCloud Drive 或其他自选位置。导出文件未加密，可能含姓名、日期和备注，请自行选择可信的保存位置与分享对象。所选存储服务按其自身规则处理文件。

04

Apple 购买与权益

Pro 购买由 Apple 的 App Store 与 StoreKit 处理。应用读取和验证 Apple 提供的交易及权益状态，以开启购买的功能；开发者不会收到你的付款卡信息。

恢复购买使用你的 Apple 购买记录，可能需要由 Apple 验证账号。JSON 备份不包含或转移 Pro 权益。Apple 对购买记录的保留和处理适用其服务条款与隐私规则。

05

手动加入系统日历

你选择“加入系统日历”时，念日将该次日期的标题、备注和日期交给 Apple 的系统编辑器，由你确认是否保存及保存到哪个日历。应用不请求完整日历读取权限，也不持续读取你的日历。

此操作只添加一次事件，不提供双向同步。之后在念日修改或删除记录，不会同步修改或删除已保存的系统日历事件；再次添加可能产生重复。日历服务的同步和保存取决于你选择的日历及系统设置。

06

保留、导出与删除

本地记录保留至你在应用中删除、用备份替换，或系统移除相应应用数据。你可在设置中导出备份并逐项删除日期。导入前会要求确认替换当前资料，请先保存需要保留的备份。

删除应用可能移除本地记录；“卸载 App”保留数据等系统操作与“删除 App”不同。你自行保存的导出文件、设备备份和系统日历事件需在对应位置单独管理。由于开发者没有你的本地日期副本，无法远程恢复或删除它们。

07

自愿发送的支持邮件

如你联系 nj.he@foxmail.com，何年金 将收到你的邮箱地址，以及你主动提供的内容或附件，用于回复、排查问题和跟进请求。邮件会通过电子邮件服务商传输及保存。

请只提供解决问题所需的信息，不要发送 Apple 账号密码、付款卡资料或未经遮盖的完整日期备份。支持记录仅在解决问题、必要跟进或依法需要的期间保留；不再需要时删除或去除身份信息。你可通过同一邮箱申请删除支持邮件，依法需要保留的部分除外。

08

本网站与 GitHub Pages

本网站使用 GitHub Pages 托管，不加入广告或行为分析脚本。GitHub 会为安全目的记录并保存访问者 IP 地址，无论访问者是否登录 GitHub。

此网站访问记录不同于念日设备内的日期资料。GitHub 对网站托管数据的处理、保存和相关权利说明见页脚的 GitHub 隐私声明；请勿将敏感个人资料提交至公开的 GitHub 页面。

09

政策更新与联系

应用或网站的信息处理方式改变时，本政策会更新，并标明更新日期。政策内容应以你正在使用的版本及实际处理方式为准。
